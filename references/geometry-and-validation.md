# 单圆弧让刀与几何验收

## 已确认的 R3 关系

以原直角点 `C` 为准，`u`、`v` 是从 `C` 沿两条原直边向外走的单位向量，`u·v=0`，`r=3 mm`：

```text
圆心 O = C + (r / sqrt(2)) * (u + v)
接点 A = C + r * sqrt(2) * u
接点 B = C + r * sqrt(2) * v
圆弧 = Part.Arc(A, C, B).toShape()
```

这是一条经过 `A、C、B` 的 180° 圆弧，长度 `πr`。原角点到圆心的距离为 `r`，中心沿 45° 平分线内移；在水平/竖直坐标下两个偏移量均为 `3/sqrt(2) ≈ 2.121320344 mm`，两条直边各从角点退让 `3*sqrt(2) ≈ 4.242640687 mm`。

例如原角点 `(0,0)`，两条边朝 `+X`、`+Y`：圆心为 `(2.121320344, 2.121320344)`，接点为 `(4.242640687,0)` 和 `(0,4.242640687)`，弧线经过 `(0,0)`，向角外略微鼓出。

用户将此描述为“圆弧内弧与原直角点相切”。执行时用上述几何关系及参考图判定，不把语言换算成普通切线圆角。不要用以下外形替代：

- 以 `C` 为圆心的 R3 圆或 270° 弧。
- 横、竖各一个圆心、拼成两个半圆的双圆弧。
- 不经过 `C`、会在原角点留下材料的普通内圆角。

外形参考在 `../assets/r3-single-arc-reference.png`。

## 哪些角需要处理

以材料在哪一侧为准：将板件外轮廓整理为逆时针、孔槽轮廓整理为顺时针后，材料始终在有向轮廓左侧。相邻两段行进向量的叉积为负且夹角为 90° 时，是要处理的材料内直角。

因此普通板件凸角不改；矩形内孔的四个角均处理；外轮廓上的凹口角处理。不要只按“多边形凹角”判断孔槽，孔内凹凸与材料内角含义相反。

共线分段不是角。非 90° 内角列为未处理项，不强套此公式。某条边两端需要退让的长度之和大于等于边长时，拒绝该局部转换并说明尺寸，不能产生倒向直线、交叉弧或缩小半径。

已有单圆弧符合圆心、半径、端点与原轮廓关系时直接保留。无法从已有弧恢复原角点时，以两条关联直线的交点和圆到该点距离验证；歧义处先单独预览。

## 排版与验收

1. 原输入应能分解成闭合平面轮廓；层级包含关系区分板料边框、板件和孔槽。移动的是带孔槽的整件。
2. 放置后的实际板件外轮廓均在板料框内；到四边的最小距离不低于设定边距。不能只检查部件中心是否在框内。
3. 两件之间的最小几何净距不低于设定间距，不能只对比原角点位置。包围盒隔开 6 毫米是充分但偏保守的条件；进一步紧缩需要真实轮廓距离与相交检查。
4. 单独检查孔槽完全留在所属板件内，带孔面有效。所有外轮廓、孔槽都闭合、无零长边、自交和意外重叠。
5. 每个目标角是一条圆弧，半径误差建议不大于 `1e-6 mm`；原角点到弧的距离近似零、到圆心距离等于半径、弧长等于 `πr`。
6. 比较处理前后板件数量、孔槽数量、未修改的外轮廓直线基准尺寸。让刀局部外凸会改变包围盒，不把这一变化当作板件缩放。
7. 不要求所有对角远距离板件、或剩余空料四边都恰好 6 毫米；报告最近距离，靠基准边和相邻行列尽量保持 6。
8. 重新读取已保存的 FCStd/交换文件，按其实际图元验证；不能仅用保存前内存状态或截图判断完成。

技能助手只做确定性的数学部分。遇到共享边、未闭合图形、套娃板件或非平面实体时，先具体判定归属和处理方式，不把一个旧吊柜的对象分组硬套到新文件。
